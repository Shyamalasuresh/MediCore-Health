# MediCore Health

**MediCore Health** is a comprehensive healthcare management application designed to streamline clinical operations, including patient management, appointments, medical records, and billing.

## Project Structure

The project is divided into separate components for better maintainability:

- **`frontend/`**: The web-based interface built with **React** and **Vite**.
- **`backend/`**: The desktop-based interface and application logic built with **Python** and **PySide6**.
- **`docs/`**: Documentation and data models.

---

## Running the Application

### 1. Web Frontend (React)
1. Navigate to the frontend directory:
   `cd frontend`
2. Install dependencies:
   `npm install`
3. Set your `GEMINI_API_KEY` in `.env.local`.
4. Start the development server:
   `npm run dev`

### 2. Desktop UI / Backend (Python)
1. Navigate to the backend directory:
   `cd backend`
2. Install Python dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python main.py`
